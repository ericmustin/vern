      How do I capture a sample?

      With an OpenTelemetry Collector

      Run a Collector with the file exporter and point your instrumented application at it. Do not add resource attributes in the Collector, so the score reflects what your SDKs emit.

      receivers:
  otlp:
    protocols:
      grpc:
        endpoint: 0.0.0.0:4317
      http:
        endpoint: 0.0.0.0:4318

processors:
  batch: {}

exporters:
  file:
    path: /samples/capture.jsonl
    format: json

service:
  pipelines:
    traces:
      receivers: [otlp]
      processors: [batch]
      exporters: [file]
    metrics:
      receivers: [otlp]
      processors: [batch]
      exporters: [file]
    logs:
      receivers: [otlp]
      processors: [batch]
      exporters: [file]

      Stop the Collector gracefully so it flushes the file, then upload capture.jsonl (compress it first if it is large):

      gzip -9 -c capture.jsonl > capture.jsonl.gz

      From the SDK, without a Collector

      Some SDKs and declarative configurations offer an experimental OTLP file exporter that writes OTLP JSON lines to stdout or a file. In a declarative configuration file it looks like this; repeat it for the meter and logger providers:

      tracer_provider:
  processors:
    - batch:
        exporter:
          otlp_file/development:
            output_stream: stdout

      Send stdout to a .jsonl file and upload it. The exporter is experimental and its name differs between SDKs, so check your SDK's documentation.
