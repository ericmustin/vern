Privacy

Your upload is processed and deleted within seconds; nothing from it is stored or logged. Or run the scorer yourself:

cp deploy/.env.example deploy/.env   # then set a password in deploy/.env
docker compose -f deploy/compose.yaml up

Run it from a checkout of the Vern repository.

What happens to an upload

  • The files are read into memory and loaded as one isolated run into the scorer's own Elasticsearch.
  • The rules run against that run's data only. The data is deleted as soon as the score is computed, whether the run succeeds or fails. A cleanup job removes anything an interrupted run leaves behind.
  • The report is sent back to your browser and not kept on the server. Report downloads are generated in your browser.

What is logged

One line per request: the method, the path, the response status, how long it took and a run identifier. Never the uploaded files, their names, their contents, query strings or request headers.

What this page loads

Only files from this server: no analytics, cookies, fonts or third-party scripts.
